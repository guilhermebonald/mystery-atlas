PRIVACY POLICY

Effective date: October 27, 2026

Home Terms

This policy describes how the "Mystery Atlas" automation (the Google Cloud application "Shorts Curiosidades") uses data obtained through the YouTube API Services.

Who uses this application

The application is a private tool used only by the owner of the Mystery Atlas YouTube channel to manage that channel. It is not offered to the public, and no other person signs in to it.

What data is accessed

  • Permission to upload videos and update video details (title, description, tags, language) on the owner's own channel.
  • The owner's own channel analytics (views, engaged views, watch time and similar aggregated metrics) to measure which video styles perform best.

The application does not access personal data of viewers, subscribers or any other YouTube users.

How the data is used and stored

Data is used only to publish videos and to produce internal performance reports for the channel owner. Access tokens and analytics data are stored on the owner's private, self-hosted server. Data is never sold, rented or shared with third parties, and it is not used for advertising.

The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube and Google

This application uses the YouTube API Services. By using it, you agree to the YouTube Terms of Service. See also the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on the Google account permissions page. When access is revoked, stored tokens stop working and the related analytics data is deleted from the owner's server on request.

Contact

Questions about this policy can be sent through the Mystery Atlas YouTube channel.
